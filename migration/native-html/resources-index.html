New law — effective January 30, 2027

Puerto Rico Authorizes Revocable Trusts

Act 153-2026, signed July 30, 2026, amends 44 articles of the Trust Act and reverses the presumption set in 2012: a trust deed that says nothing about revocability is now presumed revocable. There is no transition rule for existing trusts.
